# FRH Healthcare App — Design Timeline

Client-facing UI/UX design and delivery schedule for the FRH patient app:
24 screens across four phases, 7 September – 8 October 2026.

- **Live page:** https://sagnator.github.io/frh-design-timeline/
- **PDF (A4 landscape, 4 pages):** [FRH-Design-Timeline.pdf](FRH-Design-Timeline.pdf)

## Contents

| File | What it is |
|---|---|
| `index.html` | The timeline document. Self-contained; Google Fonts is the only external request. |
| `FRH-Design-Timeline.pdf` | Print export, A4 landscape, fonts embedded. |
| `artifact-source.html` | Body-only source as published to the Claude artifact (no `<head>` wrapper). |

Printing `index.html` from the browser (Cmd/Ctrl+P, A4 landscape, background graphics on)
reproduces the same four-page layout as the PDF.
